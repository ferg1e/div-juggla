# Div Juggla

The static site generator for my portfolio site [rysapps.com](https://www.rysapps.com).

## Install & Run

- `git clone https://github.com/ferg1e/div-juggla.git ssg`
- `cd ssg`
- `node src/index.js`
- Now you will see `index.html`, `projects.html` and `contact.html` in an `out` directory. These are the exact web pages you see on [rysapps.com](https://www.rysapps.com).
- You must then manually place a copy of `src/styles.css` into the `out` directory.
